式典資材管理

把系統放到手機主畫面，之後就能像 App 一樣從圖示開啟。

iPhone / iPad

加入主畫面

  1. 請用 Safari 開啟這一頁。
  2. 點 Safari 的 分享。
  3. 選「加入主畫面」，保持「以 Web App 開啟」啟用。
  4. 主畫面會出現「式典資材管理」圖示。
直接開啟系統

不需要描述檔、Configuration Profile、MDM、VPN、憑證或企業 App。

Android

安裝到主畫面

  1. 請用 Chrome 開啟這一頁。
  2. 點 Chrome 右上角選單。
  3. 選「安裝應用程式」或「加到主畫面」。
  4. 主畫面會出現「式典資材管理」圖示。
直接開啟系統

不需要另外安裝包裝 App。

電腦

直接使用

電腦不需要安裝，直接開啟正式系統即可。
